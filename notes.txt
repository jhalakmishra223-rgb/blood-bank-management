Q1. Why is enctype="multipart/form-data" required?

Answer:

Without it, the browser only sends text fields. Uploaded files are omitted entirely, so Django never receives them.

Q2. Where are uploaded images available in Django?

Answer:

In request.FILES, while regular form fields are available in request.POST.
Why do we use request.FILES.get("profile_picture") instead of request.POST.get("profile_picture")?

Because uploaded files are transmitted separately from normal form data. Django places file uploads in request.FILES, while text inputs are available in request.POST.
Q: Why do we customize admin.py instead of only using admin.site.register(Model)?

Answer:
admin.site.register(Model) provides basic CRUD functionality. A custom ModelAdmin allows us to configure how records are displayed, searched, filtered, ordered, and edited, making the admin panel much more efficient for real-world applications.

I recommend we use the customized ModelAdmin approach throughout BloodBridge. It will make your project look much more professional and is exactly what employers expect to see in a portfolio project.
Q2. Why did we set unique=True?
Because there should be exactly one inventory record per blood group. The available units for that group are updated in that single record rather than creating duplicate rows.
